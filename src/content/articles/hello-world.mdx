Welcome to [Hexo](https://hexo.io/)! This is your very first post. Check the [documentation](https://hexo.io/docs/) for more information. If you have any problems, see the [troubleshooting guide](https://hexo.io/docs/troubleshooting.html) or ask on [GitHub](https://github.com/hexojs/hexo/issues).

## Quick Start

### Create a new post

```bash
hexo new "My New Post"
```

More information: [Writing](https://hexo.io/docs/writing.html)

### Run the server

```bash
hexo server
```

More information: [Server](https://hexo.io/docs/server.html)

### Generate static files

```bash
hexo generate
```

More information: [Generating](https://hexo.io/docs/generating.html)

### Deploy to remote sites

```bash
hexo deploy
```

More information: [Deployment](https://hexo.io/docs/deployment.html)
